Esta página enumera todas las opciones del complemento, su valor predeterminado y la variable de entorno correspondiente. Úsela para consultar un ajuste; el README principal explica los flujos de trabajo y ofrece ejemplos.

La prioridad entre las tres formas de definir cualquier ajuste es siempre la misma: opción de línea de comandos > variable de entorno > archivo de configuración > valor predeterminado. Consulte Archivo de configuración y secretos para el archivo y Variables de entorno para las reglas de nomenclatura.

Comando

check-opencloud-security --host <Hostname> --check-hardening

Ajustes sin opción propia

El margen de caducidad de TLS, la lista de puertos de depuración y las fuentes de avisos de seguridad no tienen opción de línea de comandos. Se configuran mediante el archivo de configuración o sus variables de entorno COS_SCANNER_*, y config/check-opencloud-security.example.yml los enumera todos con un comentario.
